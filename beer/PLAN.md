# 🍺 啤酒推薦師專題
> 狀態：提案構想階段

## 核心願景
一個「居家啤酒推薦師」——像酒保一樣跟你聊天的裝置。
把啤酒放上去，感測器讀取數據，透過 LLM 用自然語言告訴你：
這大概是什麼風格、推薦飲用溫度、該用什麼杯子、還有其他小知識。

## 平台
- SoC：NT98525（已可安裝 Ubuntu）
- 對標：HiSilicon Hi3516DV300
- 有 DLA 可跑輕量模型，或透過網路串接自架的 llama-server

## 架構：實驗組 vs 對照組
- **實驗組（主力）**：感測器陣列，大部分非接觸
- **對照組（輔助）**：鏡頭，傳統 CV 方法
- 最後比較兩者在成本、效率、偵測維度上的差異

## 感測器配置（暫定）

### Base Module（非接觸）
| 感測器 | 測什麼 | 預估成本 |
|--------|--------|----------|
| MLX90614 IR | 溫度 | NT$150 |
| 430nm LED + 光電二極體 | SRM 色度 | NT$100 |
| 散射光模組 | 濁度 (NTU) | NT$200 |
| TCS34725 | RGB 色彩 | NT$120 |
| MQ-3 | 酒精蒸氣（估 ABV） | NT$50 |
| MH-Z19 | CO₂（碳酸化程度） | NT$400 |
| MQ-135 + MQ-138 | 電子鼻 VOC | NT$100 |

### Optional Module（接觸式，可插拔）
| 感測器 | 測什麼 | 預估成本 |
|--------|--------|----------|
| pH 探針 | 酸度（分辨 Sour beer） | NT$400 |
| 數位折射計 | 折射率 → 精確 ABV | NT$500 |

### 鏡頭（對照組 + 泡沫分析）
| 用途 | 備註 |
|------|------|
| 泡沫消散速度 | 純軟體分析，不額外花錢 |
| 顏色/外觀分類 | 傳統 CV approach |

### 預算
- 學校報銷：NT$1,000-2,000
- 全部買齊約 NT$2,500-3,500
- 自掏腰包部分可控

## 偵測維度分級

溫度、SRM、濁度、RGB色彩、pH、ABV（粗估）、CO₂、VOC氣味指紋、折射率、泡沫

### 做不到的
IBU 苦度、電子舌、超音波、表面張力、黏度、具體風味描述、發酵方式判定

## 系統流程
1. 感測器陣列讀取 → 正規化 → 特徵向量
2. Rule-based 初步分類 或 DLA 輕量模型
3. 特徵向量 + 分類結果 → 送給 LLM（本地或遠端）
4. LLM 用自然語言輸出推薦（像酒保聊天）

## 邊界設計
- 「不是啤酒」→ 系統輸出「無法判定」，這是合法結果
- BJCP 定義：啤酒 = 穀物為主要糖源的發酵飲料
- Fruit Beer 算、Cider/Mead 不算，在報告中定義清楚即可

## 標準操作流程 (SOP) 草案
1. 啤酒購入後靜置 ≥30 分鐘
2. 冷藏至 4-6°C
3. 取出靜置 1 分鐘
4. 45° 傾杯沿壁倒入 2/3，扶正後中央倒入 1/3
5. 放置感測平台，系統量測 60 秒
* 目的：為了氣泡偵測的統一
